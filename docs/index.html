FAQ

Docker Desktop을 따로 설치해야 하나요?

필요하지 않습니다. DockSlate는 전용 WSL 2 배포판에서 Moby 기반 Docker Engine을 실행합니다. 최초 엔진 설치에는 인터넷이 필요합니다.

Docker 엔진 사용료가 있나요?

Moby 기반 Docker Engine은 Apache-2.0 오픈소스로 엔진 사용료가 없습니다. Docker Desktop 구독은 필요하지 않습니다. Docker Hub·이미지·외부 서비스는 각각의 이용 조건이 적용됩니다. 라이선스·저작권 고지에서 구성 요소와 확인 범위를 볼 수 있습니다.

포터블은 어떻게 실행하나요?

ZIP 전체를 풀고 DockSlate.exe를 실행합니다. bin·libexec 폴더를 함께 유지하세요.

앱을 삭제하면 데이터도 지워지나요?

앱 제거로 WSL 배포판·이미지·볼륨을 자동 삭제하지 않습니다. 엔진 중지도 데이터를 지우지 않습니다.

MongoDB에 연결이 안 돼요.

컨테이너 실행 상태와 내 PC 포트를 확인하세요. 표가 32768 → 27017이면 Compass 주소는 mongodb://127.0.0.1:32768입니다. 실제 포트는 컨테이너마다 다릅니다.

지원 범위와 검증 상태는?

Compose 가져오기는 제한된 구성을 지원하며 Kubernetes 배포는 지원하지 않습니다. 설치·제거·파일 복사 등 미검증 항목은 지원·검증 현황을 확인하세요.
