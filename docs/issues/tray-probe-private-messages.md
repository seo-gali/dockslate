# 트레이 검사에서 tray-icon 비공개 메시지 의존 제거

상태: Open · 작성일: 2026-11-24 · 종류: 검사 도구의 기술 부채

GitHub: [#2](https://github.com/seo-gali/dockslate/issues/2)

## 문제

`scripts/verify-tray-controls.ps1`은 `tray_icon_app` 창 클래스와 메시지 `6002`를 알아야 트레이 클릭을 모사할 수 있다. 이 값은 Windows의 공개 트레이 입력 계약이 아니라 현재 `tray-icon` 구현에 묶여 있다. 의존성을 갱신하면 정상 앱도 트레이 검사를 실패할 수 있다. 버전 변경 때 검토하라는 주석만으로는 검사 결과의 신뢰성을 지킬 수 없다.

이 문제는 검증 도구에 있으며 앱의 실제 트레이 클릭 자체가 실패한다는 증거는 아니다. 기존 검사 코드는 이번 주석 정리에서 변경하지 않았다.

## 수정 범위

공개된 UI Automation·실제 Shell 입력 등으로 자신의 트레이 아이콘을 조작할 수 있는지 확인한다. 비공개 경로가 꼭 필요하면 지원 버전을 실행 전에 검증하고, 지원하지 않는 버전은 앱 실패와 구분해 명시적으로 차단한다. 구현을 정하기 전에 현재 검사 호출부와 Windows 동작을 확인한다.

## 완료 조건

- 앱 PID·시작 시각·실행 파일 SHA-256·아이콘 소유권 검증을 유지한다.
- 다른 앱·사용자의 트레이 항목에 메시지를 보내지 않는다.
- 비공개 숫자를 조용히 계속 사용하는 경로가 없고, 지원하지 않는 구현은 검사 불가로 보고한다.
- 숨김·다시 열기·설정·메뉴 항목·완전 종료를 격리 후보 앱에서 실제 검증한다.
- 기존 사용자 엔진·컨테이너·볼륨을 변경하지 않는다.

후속 승인으로 GitHub에 등록했고 공개 본문의 SHA-256을 준비한 입력과 대조했다. [전체 주석 분류](../results/comment-review.json)의 C21에서 발견했다. 생성에 사용한 최소 권한 일회성 workflow·입력·스크립트는 정리했다.
