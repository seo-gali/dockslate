# DockSlate 0.1.11

Docker Desktop에서 데이터를 가져오는 기능과 설치·엔진 시작 오류 수정을 포함한 Windows 미서명 개발판입니다.

## 변경 사항

- **설정 → 데이터 가져오기**: 이미지·중지된 컨테이너·볼륨을 검사·승인한 뒤 DockSlate로 복사합니다. 원본을 보존하며 같은 이름의 대상은 덮어쓰지 않습니다. 복사본은 중지 상태로 만듭니다.
- Docker Desktop의 시스템 PATH가 먼저인 경우에도 DockSlate CLI를 직접 확인해 설치를 마칠 수 있게 수정했습니다. 기존 제품과 PATH는 유지합니다.
- WSL의 systemd가 실제로 응답할 때까지 최대 30초 기다린 뒤 엔진을 시작·중지합니다. 기존 런타임에도 적용되며 재설치나 전체 WSL 강제 종료를 수행하지 않습니다.

## 확인 범위

Node 16개·Rust 18개·Windows 프로세스 7개·PATH 11개와 한국어·영어 화면을 확인했습니다. 승인된 임시 볼륨·미실행 컨테이너로 파일 내용·권한·UID/GID 왕복 복사와 원본 읽기 전용 쓰기 거부를 확인하고 정리했습니다. 기존 컨테이너·이미지·볼륨과 실행 상태는 보존했습니다.

**실제 Docker Desktop과 DockSlate 사이의 전체 이전, 전체 설치·제거와 WSL 재부팅은 미검증입니다.** 사용 중인 볼륨, Windows/WSL bind, GPU·특권·고정 IP·Swarm 설정은 자동 이전하지 않습니다. 데이터와 서비스가 정상인지 확인하기 전 Docker Desktop을 삭제하지 마세요.

앱·설치 EXE는 코드 서명 인증서가 없어 미서명입니다. Linux Docker Engine이나 WSL 커널은 이 릴리스로 자동 업데이트되지 않습니다. 이전 보안 검사에서 남은 상위 구성 요소 권고는 그대로 추적합니다.
