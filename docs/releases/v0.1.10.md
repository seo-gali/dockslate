# DockSlate 0.1.10

보안 수정과 구조 개선을 포함한 미서명 개발 버전입니다. **정식 코드 서명은 인증서가 없어 완료하지 못했습니다.**

## 변경 사항

- 창 닫기 시 Windows 트레이로 숨김, 트레이에서 열기·컨테이너·이미지·새로고침·설정·완전 종료.
- 로컬 IPC·입력 검증·웹 콘텐츠 보호 강화, 제한된 보안 거부 로그와 정기 의존성 검사 정의.
- 프로세스 시간 제한과 조회·전송 책임 분리. 기존 엔진 소유권·데이터 보호 유지.
- Tokio 1.53.3, 공식 Windows Docker CLI 29.10.0·Compose 5.8.0·Buildx 0.39.0. 이 설치판이 기존 Linux 엔진이나 WSL 커널을 자동 업데이트하지 않습니다.

## 다운로드

설치 EXE·포터블 ZIP·타사 고지 ZIP·SHA256SUMS를 제공합니다. Windows 11 x64, WSL 2.4.10 이상, WebView2가 필요합니다. 포터블은 ZIP 전체를 풀고 DockSlate.exe를 실행하세요.

## 검증 범위와 남은 항목

- 실제 앱의 Docker 이벤트 검사 18개 통과. 임시 Compose 컨테이너·이미지·볼륨·네트워크를 정리하고 기존 컨테이너 5개와 엔진 상태를 보존했습니다.
- 설치 EXE·ZIP 공통 파일 430개·문서 4개, ZIP 434개 파일 대조. 설치 보조 스크립트 일치 확인.
- Node 14개·Rust 보안 10개·Windows 프로세스 7개·오프라인 CLI 6개 검사와 원격 소스·Windows CI 통과.
- Cargo·Go 716개 버전 검사에서 권고 일치 12개 버전이 남았습니다. 플랫폼·함수 도달성 확인이 필요한 항목과 유지보수 안내를 포함하며 전체 취약점 해결로 표시하지 않습니다.
- 실제 설치·제거·로그인/재부팅·WSL 재시작·롤백은 이번 검사에서 수행하지 않았습니다.
