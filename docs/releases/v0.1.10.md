## 변경 사항

- 창의 X를 누르면 Windows 트레이로 숨기며, 아이콘 왼쪽 클릭으로 다시 엽니다.
- 오른쪽 메뉴에서 열기·컨테이너·이미지·전체 새로고침·설정·완전 종료를 사용할 수 있습니다. 앱의 한국어·영어 선택을 따릅니다.
- 완전 종료는 진행 중 작업의 기존 종료 방지를 유지하고 앱의 연결을 정리합니다. Docker Engine과 사용자 컨테이너는 계속 실행됩니다. 설치 준비창의 완료·취소는 기존 방식으로 종료합니다.

## 다운로드

- `DockSlate_0.1.10_x64-setup.exe`: Windows 설치판
- `DockSlate-0.1.10-windows-x64.zip`: 포터블. ZIP 전체를 풀고 `DockSlate.exe`를 실행하세요.
- `DockSlate-0.1.10-third-party-licenses.zip`: 구성 요소의 라이선스·소스 고지
- `SHA256SUMS.txt`: 위 세 파일의 SHA-256

Windows 11 x64, WSL 2.4.10 이상, WebView2가 필요합니다. [공식 웹사이트](https://seo-gali.github.io/dockslate/)에서 사용 방법을 확인하세요.

## 무결성 확인

받은 파일의 해시를 계산하고 `SHA256SUMS.txt`의 같은 파일명과 비교하세요.

```powershell
Get-FileHash .\DockSlate_0.1.10_x64-setup.exe -Algorithm SHA256
```
