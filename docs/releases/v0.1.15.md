# DockSlate 0.1.15

자동 시작과 Docker Desktop 이전·선택 삭제를 개선한 미서명 개발판입니다.

- 앱을 열면 설치된 전용 엔진을 기본으로 시작합니다. 설정에서 해제할 수 있으며 Windows 로그인 시 앱·엔진 실행은 별도 선택입니다.
- 컨테이너 목록의 체크한 항목에 자동 시작을 켜거나 끕니다. 켜면 Docker의 always 정책으로 엔진 재시작과 컨테이너 종료 때 다시 실행합니다.
- Desktop 목록·대상 검사·승인 후 재검사를 진행 상태가 있는 작업으로 분리하고 inspect를 16개씩 처리합니다. 읽기 시간 초과 묶음만 나누며 쓰기 명령은 자동 재시도하지 않습니다.
- 프로젝트별로 관련 항목을 선택하고, 완료 기록과 실제 대상이 일치하면 가져오기 목록에서 숨깁니다. 완료 볼륨·폴더 복사본은 재사용하며 원본의 이후 변경을 동기화하지 않습니다.
- 다중 태그 이미지는 승인한 태그·digest를 하나씩 해제하며 강제 삭제하지 않습니다. 삭제 창에서 막힌 항목을 제외하면 나머지를 다시 검사·승인합니다.
- 브라우저 우클릭 메뉴를 텍스트 복사·편집 메뉴로 바꾸고 CPU 합산 기준을 명시합니다.
