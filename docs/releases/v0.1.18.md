# DockSlate 0.1.18

**미서명 개발판 · 백신 검사 미완료**

Docker Desktop에서 가져올 때 운영체제 설명에 `Docker Desktop`이라는 문구까지 요구하던 조건을 제거했습니다. Docker Desktop 전용 Linux 연결에서 Linux 여부와 엔진 ID를 확인하며, 원본·대상이 같은 엔진인지와 실행 직전 엔진이 바뀌었는지 확인하는 검사는 유지합니다.

Windows 컨테이너 모드·운영체제 확인 실패·엔진 ID 누락을 각각 다른 오류로 안내합니다. 기존처럼 모두 “Docker Desktop Linux 엔진으로 확인된 경우에만 가져올 수 있습니다”로 표시하지 않습니다. 오류가 발생한 PC의 실제 응답은 아직 제공되지 않아 그 PC의 정확한 실패 조건과 전체 이전 성공은 미확인입니다.

새 Windows EXE·ZIP을 제작하고 파일 구성을 대조했습니다. 포터블 ZIP 435개·고지 ZIP 410개·설치 공통 파일 432개를 확인했으며, 포터블과 설치 파일 내부 앱은 개발 서버 없이 내장 화면·JS·CSS를 불러옵니다. Node 39개·Rust 49개·오프라인 CLI 6개를 검사했습니다. 원본 판별 회귀 검사는 Rust 검사에 포함됩니다.

전체 새 설치·업그레이드·제거·재부팅·롤백과 Docker Desktop 두 엔진의 실제 전체 이전은 미검증입니다. 기존 0.1.17 공개 파일과 사용자 데이터를 보존합니다.

정식 코드 서명 수단과 VirusTotal API 인증이 없어 **이 버전의 백신 검사는 미완료**입니다. 탐지 수는 미확인이며 0건으로 표시하지 않습니다. 설치 파일 반영 요청에 따라 이 상태를 알린 개발판으로 공개합니다. 이전 버전의 검사 결과를 재사용하지 않았으며 사람 확인을 우회하지 않았습니다.
