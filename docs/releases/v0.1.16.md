# DockSlate 0.1.16

**미서명 개발판 · 백신 검사 미완료**

0.1.15 설치 과정에서 `127.0.0.1` 연결 거부 화면이 나오는 문제를 수정했습니다. 앱 화면을 EXE에 내장했으며 개발 서버 없이 실행됩니다. Edge 브라우저를 추가하지 않았고 기존 WebView2를 사용합니다.

포터블 ZIP 435개 파일, 고지 ZIP 410개 파일, 설치 EXE 내부 원본 432개 파일을 대조했습니다. 포터블과 설치 파일 내부 앱의 실제 화면 2개에서 내장 JS·CSS의 정상 응답과 renderer 예외 0건을 확인했습니다. 소스 Node 33개·Rust 38개, 오프라인 CLI 6개 검사를 통과했습니다. 전체 새 설치·업그레이드·제거·재부팅·롤백은 미검증입니다.

VirusTotal 공개 업로드가 HTTP 429·`RecaptchaRequiredError`로 거부되어 이 버전의 완료된 검사 결과는 없습니다. 탐지 수는 미확인이며 0건으로 처리하지 않습니다. 사용자의 2026-11-28 “일단 공개해” 지시에 따라, 아래 파일과 내부 앱·CLI의 정확한 해시에 한정해 검사 미완료 상태의 개발판으로 공개합니다. 정식 코드 서명도 없습니다. 이전 버전의 백신 결과를 재사용하지 않습니다.
