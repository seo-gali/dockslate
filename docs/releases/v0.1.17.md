# DockSlate 0.1.17

**미서명 개발판 · 백신 검사 미완료**

Docker Desktop에서 실행 설정만 Compose 프로젝트로 가져오는 기능과 컨테이너 작업 대기열을 추가했습니다.

- Compose 프로젝트를 한 번에 시작·중지·재시작합니다. 시작은 의존 순서와 준비 조건을 따르고, 중지는 역순으로 진행합니다.
- 컨테이너 작업 중에도 다른 컨테이너 작업을 대기열에 넣고 목록·선택·상세 화면을 사용할 수 있습니다.
- 설정만 Compose로 가져오기는 원본을 변경하지 않습니다. 필요한 이미지가 DockSlate 엔진에 있어야 하며, 데이터는 복사하지 않고 빈 볼륨을 만듭니다. 호스트 폴더 연결 등 지원하지 않는 설정은 거절합니다.
- 이미지 검사·컨테이너 생성·시작 명령의 제한을 120초로 조정하고, 조회 준비가 앱 전체의 작업을 잠그지 않도록 수정했습니다. 일반 API 전체의 제한을 늘리지는 않았습니다.
- Docker 이벤트의 `Connection: close` 응답에서 소켓 참조 오류로 재연결을 반복하던 문제를 수정했습니다.
- 현재 코드에 맞춰 사용·개발 문서를 정리했습니다.

포터블 ZIP 435개, 고지 ZIP 410개, 설치 EXE의 공통 파일 432개를 대조했습니다. 개발 서버 없이 포터블과 설치 파일 내부 앱의 화면·JS·CSS를 확인했습니다. Node 38개·Rust 47개·오프라인 CLI 6개와 화면 fixture 15개를 검사했고, 원격 Linux·Windows 소스 검사는 성공했습니다.

다른 Windows PC의 실제 사용자 프로젝트와 Docker Desktop 두 엔진의 전체 이전, 전체 새 설치·업그레이드·제거·재부팅·롤백은 미검증입니다. 환경에 따라 `container create` 실패 원인을 추가로 확인해야 할 수 있습니다.

정식 코드 서명 수단과 VirusTotal API 인증이 제공되지 않아 **이 버전의 백신 검사는 미완료**입니다. 탐지 수는 미확인이며 0건으로 표시하지 않습니다. 사용자의 공개 지시에 따라 이 상태를 밝히고 개발판으로 제공합니다. 이전 버전의 검사 결과를 재사용하지 않았습니다.
