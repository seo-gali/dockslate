## 변경 사항

외부 Docker·Compose 명령으로 바뀐 컨테이너·이미지·볼륨·네트워크 목록을 자동 갱신합니다. 연결이 끊겼다가 복구되면 현재 목록을 다시 읽습니다.

## 다운로드

- `DockSlate_0.1.7_x64-setup.exe`: Windows 설치판
- `DockSlate-0.1.7-windows-x64.zip`: 포터블. ZIP 전체를 풀고 `DockSlate.exe`를 실행하세요.
- `DockSlate-0.1.7-third-party-licenses.zip`: 구성 요소의 라이선스·소스 고지
- `SHA256SUMS.txt`: 위 세 파일의 SHA-256

Windows 11 x64, WSL 2.4.10 이상, WebView2가 필요합니다. 사용 방법은 [공식 웹사이트](https://seo-gali.github.io/dockslate/)에서 확인하세요.

## 무결성 확인

PowerShell에서 받은 파일의 해시를 계산하고 `SHA256SUMS.txt`의 같은 파일명과 비교하세요.

```powershell
Get-FileHash .\DockSlate_0.1.7_x64-setup.exe -Algorithm SHA256
```
