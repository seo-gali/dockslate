# DockSlate 0.1.14

Docker Desktop 목록 조회와 가져오기 대상 검사에서 발생하던 시간 초과를 줄이는 미서명 개발판이다.

- Desktop 원본 조회의 명령별 제한을 30초에서 120초로 늘렸다.
- 검사 완료 시점부터 승인 유효 시간 120초를 계산한다.
- Desktop 원본의 core 명령에서 DockSlate 프록시·Compose/Buildx를 불필요하게 준비하지 않는다.
- 실패한 엔진과 명령 단계를 표시하며 원시 설정값은 오류에 노출하지 않는다.
- 사용·개발·웹 안내를 현재 기능과 검사 범위에 맞췄다.

원본 정상 중지·복사 제한, 소유권·승인 검사와 기존 데이터 보존 경계는 유지했다. 제작 소스는 eb30c7f2985863fc209dff99813501bc9ccb8189이며, 이후 주석·ADR·검사 정리는 앱 실행 동작 변경 없이 별도로 반영했다. 공개 파일은 이미 검증한 같은 EXE·ZIP이다.

## 백신 검사와 남은 확인
