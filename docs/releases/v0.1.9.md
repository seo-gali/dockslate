## 변경 사항

- 설정에서 엔진 자동 시작과 Windows 로그인 시 DockSlate 창 열기를 각각 선택할 수 있습니다. 기본값은 둘 다 꺼짐입니다.
- 컨테이너 목록에서 체크박스로 여러 항목을 선택해 시작·중지·재시작할 수 있습니다.
- 설치·제거 마지막 환경 변경 알림의 대기 예산을 약 2초로 제한하고, 등록 처리 단계와 경과 시간을 표시합니다. 첫 업그레이드에서 실행되는 이전 버전의 제거 프로그램에는 적용되지 않습니다.

## 다운로드

- `DockSlate_0.1.9_x64-setup.exe`: Windows 설치판
- `DockSlate-0.1.9-windows-x64.zip`: 포터블. ZIP 전체를 풀고 `DockSlate.exe`를 실행하세요.
- `DockSlate-0.1.9-third-party-licenses.zip`: 구성 요소의 라이선스·소스 고지
- `SHA256SUMS.txt`: 위 세 파일의 SHA-256

Windows 11 x64, WSL 2.4.10 이상, WebView2가 필요합니다. 사용 방법은 [공식 웹사이트](https://seo-gali.github.io/dockslate/)에서 확인하세요.

## 무결성 확인

PowerShell에서 받은 파일의 해시를 계산하고 `SHA256SUMS.txt`의 같은 파일명과 비교하세요.

```powershell
Get-FileHash .\DockSlate_0.1.9_x64-setup.exe -Algorithm SHA256
```
