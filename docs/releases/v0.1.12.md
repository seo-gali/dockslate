# DockSlate 0.1.12

**보안 고지: 포함된 `DockSlate.exe`를 DeepInstinct가 `MALICIOUS`로 분류했다(탐지 1건). 오탐 여부는 확인되지 않았다. 사용자가 이 결과를 확인한 뒤 개발판 공개를 승인했다. 정식 서명도 미완료다.**

Windows 설치 완료 검사에서 같은 WSL 경로를 다른 런타임으로 오판하던 문제를 수정한 미서명 개발판(prerelease)이다.

- `\\?\C:\...`와 `C:\...` 표기, 대소문자와 경로 정규화를 기존 Windows API로 비교한다. 사용자명·설치 드라이브·설치 폴더를 고정하지 않는다. 등록 ID·설치 ID·엔진 버전·rootfs 해시와 기존 파일·프로세스 검증은 유지한다.
- 첫 Windows CLI 조회와 엔진 ID 확인이 끝난 뒤 Compose·Buildx 버전을 병렬 검사한다. 구형 공식 플러그인을 동시에 갱신하면서 발생하던 접근 거부·충돌을 피한다.
- CLI 실패 안내에 실제 오류와 종료 코드를 포함한다. 종료 코드가 0이어도 필수 출력이 없으면 완료 처리하지 않는다.
- 데이터 가져오기 패널의 본문·설명·버튼을 다른 설정 패널과 같은 여백으로 정렬한다.
- Docker Desktop이 있으면 기존 자료를 DockSlate 엔진으로 선택 복사하고 확인한 뒤 Desktop을 제거할 수 있다. Desktop이 없으면 가져오기 없이 단독 설치·사용한다. 이미 설치된 소유 엔진은 기존 데이터를 보존해 사용한다. [이전 범위](https://github.com/seo-gali/dockslate/blob/main/docs/MIGRATION.md)를 확인한다.

앱·CLI·설치판은 미서명 개발판이다. 의존성·Linux 엔진·WSL 커널 버전은 변경하지 않는다. 기존 의존성 보안 권고를 이번 변경으로 해결했다고 간주하지 않는다. 실제 Docker Desktop 전체 이전, 원격 PC의 전체 설치 완료, 설치·제거·콜드 부팅·롤백은 별도 검증이 필요하다.

[경로·CLI 검사 기록](https://github.com/seo-gali/dockslate/blob/main/docs/results/windows-cli-contract.md#엔진-연결)에서 실패 재현·수정·검증 범위를 확인한다. 배포 파일 해시는 첨부한 `SHA256SUMS.txt`에서 확인한다.
