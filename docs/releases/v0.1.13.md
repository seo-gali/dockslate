# DockSlate 0.1.13

Docker Desktop에서 여러 컨테이너와 연결된 데이터를 한 번에 옮기는 기능을 포함한 미서명 개발 빌드다. 새 EXE·ZIP의 공개 백신 검사는 별도로 기록하며 이전 버전의 검사 결과를 이 파일에 적용하지 않는다.

- 전체 선택·종류별 선택을 추가했다. 같은 이미지 ID의 여러 태그는 한 번만 선택한다.
- 승인한 실행 중 원본을 정상 중지한 뒤 복사한다. 다른 실행 컨테이너가 같은 데이터를 쓰면 함께 선택하도록 안내하며, 3분 안에 정상 종료되지 않으면 강제 종료 없이 중단한다.
- Windows·WSL·Linux의 bind 파일·폴더를 새 볼륨으로 복사하고 컨테이너 안 경로·읽기 전용·UID/GID·파일 권한을 유지하는 경로를 추가했다. 단일 파일과 공유·중첩 경로도 처리한다. 원래 호스트 폴더와 이후 변경은 동기화되지 않는다.
- Traefik·Runner 등의 Docker 소켓을 DockSlate 엔진 소켓으로 다시 연결한다. 엔진 관리 권한이 생기는 대상을 승인창에 표시한다.
- 모든 복사본을 만든 뒤 원래 실행 중이던 대상만 시작한다. Compose 의존성 라벨의 순서를 참고하며 서비스 건강 확인을 대신하지 않는다.
- 이전 이력과 설정이 같은 네트워크는 재사용한다. 기존 컨테이너·볼륨·다른 이미지 태그는 덮어쓰지 않는다.
- 실패 시 중지한 원본과 시작한 복사본, 이미 복사한 항목을 따로 표시하고 데이터를 보존한다.

앱·CLI·설치 EXE는 정식 서명되지 않았다. 의존성·Linux 엔진·WSL 커널 버전은 바꾸지 않았다. 특권·장치·host/container 네트워크·고정 IP·Swarm과 지원하지 않는 propagation은 계속 차단한다. 실제 Docker Desktop 두 엔진 사이의 전체 이전과 사용자의 운영 서비스는 검증하지 않았다.

배포 파일의 정확한 SHA-256은 함께 올린 `SHA256SUMS.txt`를 기준으로 확인한다. 백신 결과·서명·전체 설치 검증이 끝나기 전에는 검증된 정식 배포본으로 표시하지 않는다.
