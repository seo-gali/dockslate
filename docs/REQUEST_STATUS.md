# 사용자 요청 체크리스트

기준: 2026-10-19. **전체 완료 아님.** ‘구현’과 ‘실제 검증’을 구분한다.

- **최신 화면**: 최신 배포 자산을 브라우저에서 확인. 네이티브 엔진 미포함.
- **이전 EXE**: 최신 변경 전의 실제 Windows 앱·엔진 검사.
- **남음**: 코드·컴파일만 확인했거나 해당 사용자 경로 미실행.

## 이미지 · 빌드 · 리소스

| 요청 | 구현 | 실제 검증 |
| --- | --- | --- |
| 이미지 참조 컨테이너 함께 삭제 | 별도 선택·대상 확인·승인. 중지/생성/dead만 허용, 볼륨 보존 | 격리 생성/중지 참조·승인 거절·참조 변경 차단 통과. 실행 중 참조 시나리오 남음 |
| Dockerfile 파일 선택 후 빌드 | Windows 선택창·부모 폴더 컨텍스트 | 새 선택→빌드 E2E 남음 |
| Compose 파일 선택 후 자동 빌드 | 제한 검증·빌드·별도 실행 승인 | 새 UI 선택→빌드→실행 E2E 남음. 이전 CLI의 격리 2개 서비스 빌드는 통과 |
| deployment.yaml 전체 빌드 여부 | Compose 내용이면 제한 가져오기, Kubernetes 형식은 미지원 | 사용자 실제 프로젝트 입력 미제공·미검증 |
| 실행 설정에서 새 볼륨 생성 | 생성 후 새 컨테이너에 선택 | 생성→연결→실행 E2E 남음 |
| 실행 설정에서 네트워크 생성 | bridge·internal 생성 후 선택 | 기존 화면·네트워크 작업 확인, 최신 실행 경로 남음 |
| 볼륨을 기존 컨테이너에 연결 | 자동 연결 없음. 마운트 변경은 재생성 필요 | 제한을 안내서에 명시 |
| 실행 명령어 확인 팝업 | Docker(WSL) 기본 / PowerShell 7.3+ | 두 형식 구문 검사 통과. 복사 명령 실제 실행 남음 |
| 볼륨·네트워크 통합 메뉴 | Resources → Volumes / Networks | 최신 탭·상태 보존 통과 |
| 볼륨 작업 전체 | 생성·복제·참조·파일·tar 입출력·비우기·삭제 | 이전 EXE 11개 실제 경로 통과 |
| 네트워크 관리 | 참조·IPAM·생성·미사용 삭제 승인 | 기본/참조 삭제 차단·승인 토큰·지정 네트워크 삭제 통과 |
| 빌드 관리 | 진행·기록·빌더·기록 가져오기/내보내기 | 이전 6개 실제 경로 통과. 원격 TLS/SSH/Kubernetes 미지원 |

Compose 가져오기 제한: 1~16개 서비스, 프로젝트 내부 상대 컨텍스트·새 named volume·bridge. include/extends/env_file/치환/secrets/configs/bind/privileged/장치/외부 리소스는 차단한다.

## 런타임 · 배포 · 보안

| 요청 | 상태 | 남은 일 |
| --- | --- | --- |
| Docker Desktop 없는 독립 사용 | 전용 WSL Moby 설치·시작·API·컨테이너·포트·mount 이전 실제 검증 통과 | 최신 EXE의 실제 조작·로그 검증도 통과 |
| Apple container·Davit 적용 검토 | macOS 엔진 교체 미적용. 화면 밀도·작업 중심 UI, WSL 파일 경계 검토 | I/O 성능 비교 측정 없음 |
| 삭제·재설치 시 WSL 처리 | 앱 파일과 WSL 데이터를 분리. 설치판에서도 기존 엔진 재사용·제거 시 데이터 보존 | 실제 설치·제거 E2E 남음. WSL 삭제·초기화는 하지 않음 |
| 디스크 정리·압축 | 정확한 대상 정리, WSL 식별·압축 조건·차단 | 실제 VHDX 압축·UAC 승인 미검증 |
| 파일로 HTML 열기 | root/dist 진입점에 정적 안내, 자체 완결 HTML 가이드 | 두 file:// 진입점·실제 다운로드·공유 HTML·추출 ZIP 안내·모바일 등 10개 통과 |
| EXE·ZIP 다운로드·코드 서명 | 사용자 요청으로 미서명 개발 빌드 다운로드 허용. 강제 서명 차단 제거, 해시 검증 유지 | 정식 서명 미완료, 접근 경고 원인 미확인. [상태](results/code-signing.md) |
| 설치 파일 | 설치 중 엔진 대상 자동 확인 → 승인 후 설치·시작 → Windows CLI·Compose·Buildx 자동 검증. 긴 PATH 처리를 .NET 레지스트리 API로 교체 | 사용자 설치에서 1,199자 PATH로 중단됨. 수정 후 임시 키에서 긴 PATH·재설치·제거 등 8개 검증 통과. 전체 설치·제거 완료는 미검증. 로컬 NSIS 읽기 오류는 남음 |
| 보안 제품 경고 | 접근 대상 미확인. 신뢰/예외 등록 없음. 사용자 명시 승인 후 지정 EXE 새 프로필 검증 | 경고 대상 확인, 실행 가능한 정상 검사 |
