현재 예제는 [Node.js 웹 앱](../examples/basic-web/README.md)이다. 파일 선택 직후 이미지 빌드가 시작되고 컨테이너 실행은 별도 동작이다. 사용 가이드 영상은 [YouTube](https://youtu.be/EbL7LkbNrPY)에서 제공하며 로컬 media 폴더는 Git에 포함하지 않는다.

아래 표의 기존 통과는 연결된 기록의 버전·시점에 해당한다. 과거 브라우저 화면이나 이전 EXE 검사로 최신 앱 전체 검증을 대신하지 않는다. **남음**은 해당 사용자 경로 미실행을 뜻한다. [프로덕션 배포 전 10개 점검](results/production-readiness.md)의 미서명·접근 경고 원인·전체 회귀·데이터 복구 항목은 남아 있다.
