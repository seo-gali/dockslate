# 사용자 요청 체크리스트

갱신: 2026-10-30 · 개발판 0.1.3. **정식 배포 점검 전체 완료는 아님.** [최신 표·선택 목록 검증](results/release-0.1.3.md)은 실제 22개 검사다. 설치 EXE 생성과 내부 앱·CLI·라이선스·예제 검증을 완료했고 다운로드를 0.1.3으로 갱신했다. 실제 설치·제거는 실행하지 않았다. [0.1.2 UI·예제 검증](results/release-0.1.2.md)의 15개와 [0.1.1 네이티브 기록](results/ui-release-0.1.1.json)의 40개는 당시 해시 범위를 유지한다.

0.1.2 당시 표 위 선택 필터·상단 새로고침·중복 버튼 정리와 Dockerfile·Compose 빌드·HTTP 포트·볼륨 연결을 확인했다. 현재 예제는 [Node.js 웹 앱](../examples/basic-web/README.md)이며 두 CLI 빌드와 로컬 HTTP 검사를 통과했다. 컨테이너 실행은 사용자가 진행한다.

0.1.2 설치 EXE·ZIP·고지 ZIP의 파일·내부 해시를 검증했고, 구버전 0.1.1 다운로드와 일회성 workflow를 제거했다. 실제 새 설치·제거와 전체 회귀 검사는 별도 미검증이다.

0.1.1 설치 EXE·포터블 ZIP·고지 ZIP을 갱신했다. 설치판 내부 바이너리·고지를 대조하고 구버전 산출물과 일회성 빌드 workflow를 제거했다. [빌드·패키지 검증](results/release-0.1.1.md). 실제 설치·제거 실행과 보안 경고 해소는 별도 미검증이다.

**프로덕션 배포 전 10개 항목:** [점검 결과](results/production-readiness.md). 실제 DB 검사는 통과했지만 서명·보안 경고·전체 회귀·롤백 검증이 남아 있다.

- **최신 화면**: 최신 배포 자산을 브라우저에서 확인. 네이티브 엔진 미포함.
- **이전 EXE**: 최신 변경 전의 실제 Windows 앱·엔진 검사.
- **남음**: 코드·컴파일만 확인했거나 해당 사용자 경로 미실행.

0.1.4 로컬 후보의 [실제 Windows 앱 검사 10개](results/ui-workflow-0.1.4.json)는 통과했다. 파일 선택 닫기 통일·다시 빌드·진행 상태·프로젝트 표시명·그룹 접기·정리 헤더 체크박스·반응형 확인창을 포함한다. 테스트 컨테이너 2개·이미지 3개만 제거했고 기존 컨테이너 ID·상태와 볼륨·네트워크 ID는 유지했다. 공개 0.1.3 설치 파일은 유지하며 새 설치 EXE는 아직 없다. [상세](results/release-0.1.4.md).
