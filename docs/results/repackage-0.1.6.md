# 0.1.6 설치 EXE·ZIP 재패키징

2026-11-04. [최적화 소스](https://github.com/seo-gali/dockslate/commit/49da590b61275d38876e920a1977863f153f8c30)를 기존 0.1.6 설치 EXE·포터블 ZIP에 반영한다. 앱·의존성 버전과 다운로드 파일명은 유지하며 파일 내용·크기·SHA-256을 갱신한다. 2026-10-31의 [최초 제작 기록](release-0.1.6.md)은 당시 파일의 기록이다.

## 생성·내부 검증

- 앱 재빌드·CLI 빌드·locked/offline Rust 검사 통과. 검증한 앱의 실제 네이티브 검사 14개는 [핫 패스 기록](hot-path-review.md)에 있다.
- 포터블에서 실행한 Docker·디버그 버전·Compose·Buildx 명령 4개 통과. 별도 앱 데이터 폴더를 사용하고 엔진 변경은 수행하지 않았다.
- ZIP 전체 파일을 포터블 폴더와 크기·SHA-256으로 대조했다. 정확한 파일 수와 최종 외부 ZIP 해시는 [구조화된 결과](repackage-0.1.6.json)에 기록한다.
- 로컬 NSIS는 `src-tauri/installer/user-path.ps1`을 읽지 못해 종료 1이었다. 일반 사용자 환경에서도 같은 오류를 확인했으며 보안 설정은 변경하지 않았다.
- [GitHub 패키징](https://github.com/seo-gali/dockslate/actions/runs/41841670394)이 성공했다. 검증한 앱·CLI 입력을 복원하고 PATH 보존 검사 후 설치 EXE를 생성했다. Action 해시 오기로 시작 단계에서 실패한 앞선 실행에서는 패키징이 시작되지 않았다.
- 받은 아티팩트의 크기·SHA-256을 공식 GitHub 영수증과 대조했다. 설치 EXE 내부 앱·CLI, 공식 구성 요소 3개, 라이선스·소스 375개, 예제 5개, 안내·결과 문서 8개와 PATH 도우미가 검증한 파일과 일치했다.
- 설치 EXE·ZIP에 들어 있는 앱 SHA-256은 `E14AA485512763EE5FC6F68FE102EF25617C6885B5478B15E9128C13094069FB`, CLI는 `B0EAC4D24279E74CA13E58096D63973917E7A7EF313CBE2758E97C41D3497B59`다.

## 게시·문서 범위

공개 사이트의 두 다운로드와 크기·SHA-256을 함께 갱신한다. 기존 고지 ZIP·과거 고지 URL은 보존한다. 게시 후 실제 HTTP 다운로드 대조 결과와 임시 workflow·입력 파일 제거 여부는 [최종 결과](repackage-0.1.6.json)에 기록한다.

패키지 안의 문서는 생성 시점의 스냅샷이다. 외부 ZIP 자신의 해시와 이후 게시 결과는 저장소의 최종 영수증이 기준이다. [배포 전 10개 점검](production-readiness.md#016-재패키징)에서 수행·미검증을 구분한다.

설치·제거 실행, 전체 컨테이너 회귀, 새 서명·보안 제품 검사는 이번 검증에 포함하지 않았다. 기존 미서명 상태와 로컬 NSIS 읽기 오류는 남아 있다. 사용자 WSL·컨테이너·이미지·볼륨을 설치·삭제하거나 정리하지 않았다.
