# AGENTS 지침 진단과 수정안

2026-10-31. 프로젝트 `AGENTS.md`와 직접 참조하는 기준 문서의 필요한 절을 검사했다. 현재 지침의 로컬 파일·앵커 참조 11개는 모두 유효하다. 루트 정리로 기준 문서 2개를 `docs/`로 이동한 뒤 경로를 맞췄으며 같은 참조 검사는 다시 통과했다. 지시의 의미 변경은 아래 제안 단계다.

## 충돌·모호한 적용 범위

우선순위로 해결할 수 없는 명백한 규칙 충돌은 확인하지 못했다. 로컬 자율 실행과 배포·데이터 변경 사전 승인은 일반 규칙과 예외라서 모순이 아니다. 다음 표현은 작업 종류를 구분하지 않으면 과도하게 적용될 수 있다.

| 현재 표현 | 해석 위험 | 수정안 |
| --- | --- | --- |
| 문서 → 실패 확인 → 최소 구현 → 불필요한 코드·문서 삭제 순서 | 문서만 고칠 때도 실행 실패 재현·불필요한 검증 준비를 요구할 수 있음 | 동작 변경에만 필요한 재현·관련 검증을 요구하고 문서 작업은 링크·내용 확인으로 제한 |
| 보존용 사본은 남기지 않음 | 코드 임시 복사본과 데이터 복구용 설정·조사 원본을 혼동할 수 있음 | 불필요한 코드 임시 사본을 남기지 않되 승인된 복구 자료·법적 고지·조사 원본은 보존 |
| 문서가 기준 / 코드와 상충하면 기존 코드 작성 방식 따름 | 요구 동작과 구현 스타일의 우선순위를 혼동할 수 있음 | 동작·지원 범위는 현재 요구와 기준 문서를 따르고 구현 패턴은 기존 코드를 참고한다고 구분 |
| 발견한 상충점을 마지막에 모두 나열 | 사소한 문구 차이까지 긴 최종 보고로 이어질 수 있음 | 동작·권한·데이터·지원 범위에 영향 있는 차이와 처리만 보고 |

## 없는 참조와 중복·구형 문구

AGENTS의 없는 파일·깨진 앵커는 0개다. 저장소 다른 문서에는 제거된 0.1.0 다운로드 링크 2개와 비공개 로컬 조사 산출물 링크 1개가 있었으며, 당시 파일명·검증 범위를 유지한 텍스트로 고쳐 현재 다운로드와 구분했다. 이것을 AGENTS 자체의 누락 참조로 집계하지 않는다.

전역 승인 원칙을 프로젝트에서 반복하는 문구는 줄일 여지가 있지만, 엔진 소유권·WSL 전체 종료·볼륨 보존처럼 이 프로젝트에 특화된 경계는 유지해야 한다. 배포 전 10개 점검은 배포에 적용하고 문서만 고치는 작업에 전체 회귀로 확대하지 않는 편이 명확하다. 단위 테스트를 일괄 금지하는 표현은 참조 문서 `CODING_STANDARDS.md`의 정책이며 AGENTS 본문의 독립 규칙과 구분해야 한다. 현재 정책을 임의로 바꾸지는 않았다.

## 검증한 한 문장

[실제 A/B 실행](agents-ab.md)에서는 첫 번째 순서 규칙 한 문장만 수정했다. 입력 토큰과 환산 비용은 감소했지만 실행 시간은 늘었고 각 실행의 정리 범위도 달랐다. 따라서 명료화 제안은 가능하지만 전체 개선이나 과거 오도의 원인으로 확정하지 않는다. 실제 프로젝트에는 실험 문구를 자동 채택하지 않았다.
