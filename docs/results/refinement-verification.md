## 최신 프런트엔드 검증

[실제 배포 프런트엔드 검사 9개](frontend-refinements-e2e.json)가 통과했다. 유효한 디지털 서명의 Chrome을 작업 폴더 아래 별도 임시 프로필로 실행했다. 기존 브라우저 프로필을 사용하지 않았으며 Tauri 백엔드를 주입하거나 엔진 응답을 대체하지 않았다.

- 한국어 첫 화면에서 진입 코드와 Overview만 로드하고, 방문하지 않은 메뉴와 영어 번역 코드는 로드하지 않음.
- 영어 선택 시 번역 청크 로드, 즉시 전환, 페이지 재로드 뒤 선택 유지.
- 지연 로드한 7개 화면에서 처리되지 않은 JavaScript 예외 없음.
- Settings의 화면·런타임·연결 정보 탭, 글자 크기와 테마.
- Images의 로컬·Docker Hub 탭 및 메뉴 왕복 뒤 상태 보존.
- Resources의 볼륨·네트워크 탭 상태 보존.
- Builds의 파일 가져오기 탭과 엔진 미연결 시 작업 비활성화.

이 검사는 최신 네이티브 엔진 기능이나 팝업 안의 실제 데이터를 검증한 결과가 아니다.

재사용 검증 코드는 `scripts/verify-frontend-refinements.mjs`다. 별도로 준비한 임시 브라우저의 session JSON을 인수로 받으며 브라우저·엔진을 직접 시작하지 않는다.

## 최적화 근거와 측정

[프로덕션 파일 크기](bundle-inspection.json)는 `npm run build` 후 `node scripts/inspect-bundle.mjs`로 측정했다. 네트워크·CPU·메모리 벤치마크가 아니다.

| JavaScript 범위 | 크기 | gzip |
| --- | ---: | ---: |
| 변경 전 진입 파일 | 약 496.91KB | 약 146.31KB |
| 현재 진입 파일 | 약 277.41KB | 약 86.69KB |
| 한국어 첫 화면의 정적 의존성·Overview 포함 | 약 281.19KB | 약 87.98KB |
| 영어 첫 화면·번역 포함 | 약 342.82KB | 약 106.62KB |
| 모든 기능 청크 합계 | 약 504.55KB | 약 157.17KB |

진입 파일은 44.17% 감소했다. 전체 기능 합계가 줄었다는 의미는 아니다. 수치는 file:// 안내·상대 자산 경로 변경 후 다시 측정했다.

- 렌더링: 모든 화면을 시작 때 마운트하던 구조와 전체 대시보드 객체 구독을 확인했다. 첫 방문 지연 마운트·상태 보존, 페이지와 컨테이너 행 memo, 안정된 콜백, 데이터 종류별 동일 스냅샷 반환으로 관련 없는 갱신을 분리했다. 실제 렌더 횟수 감소율은 측정하지 않았다.
- 요청·캐시: 공용 조회와 진행 중 요청을 공유한다. 로그·파일·Inspect·이미지 기본 정보는 제한된 메모리 캐시를 사용하며, 컨테이너 정보는 새로고침 revision으로 구분한다. 런타임 조회 캐시는 잠금 핸들을 보관하지 않고, 사용할 때 소유권·WSL 등록·keeper를 검증한다. 실제 변경은 엔진 ID와 상태를 다시 검사한다.
- 쿼리: 기본 스냅샷은 컨테이너·이미지·사용량·네트워크를 병렬로 한 번씩 읽고 목록·개요·볼륨에서 공유한다. 이미지 목록의 불필요한 `shared-size=1` 계산을 제거했다. 이미지 참조 수와 정리 후보는 컨테이너를 이미지마다 반복 탐색하던 대신 맵·집합을 사용한다. 볼륨 목록은 기존 일괄 참조 집계를 유지한다. 목록 행별 추가 조회는 하지 않는다. 삭제 전 개별 참조 검증과 컨테이너별 통계는 안전성·Docker API 제약 때문에 유지한다.
- 이미지·폰트·스크립트: UI는 SVG와 시스템 폰트를 사용한다. 배포 자산에 래스터 이미지·웹 폰트 파일은 없다. 페이지별 JS·파일 탐색기 CSS·영어 번역을 분리했다. 새 의존성이나 lock 변경은 없다.

## 중단·미검증 범위

사용자가 [브라우징 데이터 접근 경고](browsing-data-alert.md)를 보고한 뒤 DockSlate EXE 재실행을 중단했다. Defender 검사는 기능 비활성화로 실행되지 않았으며 안전 판정으로 기록하지 않는다.

최신 EXE의 통계가 합쳐진 상세·로그/JSON 여백, 실행 중 컨테이너의 버튼 전환, 인라인 볼륨 생성·실행, Dockerfile·Compose 파일 선택부터 실제 빌드·실행까지의 새 경로는 네이티브 E2E가 남아 있다. 생성한 Docker 셸 명령과 PowerShell 명령의 구문 검사는 통과했지만 명령을 실행하지 않았다. 사용자의 실제 프로젝트 빌드, 원격 TLS 빌더, 실제 VHDX 압축도 검증하지 않았다.
