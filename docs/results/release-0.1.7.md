# DockSlate 0.1.7

2026-11-05. 외부 Docker·Compose 변경을 이벤트로 감지해 컨테이너·이미지·볼륨·네트워크 목록을 자동 갱신한다. 유휴 목록 폴링·결과 캐시는 추가하지 않았다.

앱·CLI 빌드와 locked/offline Rust 검사, 라이선스 인벤토리 검사, [실제 Windows 검사 24개](engine-events.md)가 통과했다. 이미지·볼륨 임시 생성·삭제와 DockSlate WSL 재시작 후 SQL 컨테이너 실행 상태 복원을 포함한다. 의존성 버전은 유지하고 앱 버전 정보만 변경했다.

포터블 ZIP 내부 604개 파일·CLI 명령 4개와 GitHub 1회 패키징 설치 EXE의 앱·CLI·고지·문서·PATH 도우미 대조가 통과했다. 공식 사이트의 CSS·JavaScript·가이드와 다운로드 3개도 실제 HTTP 크기·SHA-256 대조를 통과했다. 이전 0.1.6 라이선스 ZIP의 두 공개 경로도 보존·대조했다. 최종 결과는 [배포 영수증](release-0.1.7.json)에 기록한다. 패키지에 들어가는 문서는 제작 시점의 스냅샷이다.

실제 설치·제거, 장시간 부하, 서명·새 보안 스캔은 이번 검사에 포함하지 않는다. 기존 커널·데이터 형식 변경은 없다.

구버전 앱 배포물·포터블 폴더와 1회 패키징 workflow·입력 ZIP, 검증용 임시 생성물을 정리했다. 현재 포터블·사용자 데이터·과거 고지 아카이브는 유지한다. 재시작 검사 당시 SQL 실행 상태를 복원했으며, 별도의 게시 전 읽기 확인에서는 전용 엔진이 중지 상태였다. 게시를 위해 다시 시작하지 않았다.
