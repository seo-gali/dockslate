# DockSlate 0.1.7

2026-11-05. 외부 Docker·Compose 변경을 이벤트로 감지해 컨테이너·이미지·볼륨·네트워크 목록을 자동 갱신한다. 유휴 목록 폴링·결과 캐시는 추가하지 않았다.

앱·CLI 빌드와 locked/offline Rust 검사, 라이선스 인벤토리 검사, [실제 Windows 검사 24개](engine-events.md)가 통과했다. 이미지·볼륨 임시 생성·삭제와 DockSlate WSL 재시작 후 SQL 컨테이너 실행 상태 복원을 포함한다. 의존성 버전은 유지하고 앱 버전 정보만 변경했다.

설치 EXE·ZIP 제작과 공개 HTTP 검증은 별도 단계다. 최종 결과는 [배포 영수증](release-0.1.7.json)에 기록한다. 패키지에 들어가는 문서는 제작 시점의 스냅샷이다.

실제 설치·제거, 장시간 부하, 서명·새 보안 스캔은 이번 검사에 포함하지 않는다. 기존 커널·데이터 형식 변경은 없다.
