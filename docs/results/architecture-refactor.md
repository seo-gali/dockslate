# 구조 점검 후속 수정

기준: 2026-11-16, `8089ea7` 이후 로컬 변경. 당시 개발판 0.1.10·공개판 0.1.9를 유지했다. 현재 구조는 [구조 문서](../ARCHITECTURE_REVIEW.md)의 현재 책임 표를, 공개 제작·CI는 [0.1.13 기록](release-0.1.13.md)을 따른다. [최초 감사](../ARCHITECTURE_REVIEW.md)의 9개 항목을 소스와 검사 도구에 적용했으며 새 설치판 제작·공개 배포와 구분한다.

## 변경

- Windows 프로세스의 직접 자식 종료 뒤에도 남던 입출력 대기를 소유 핸들의 `CancelIoEx`·`CancelSynchronousIo`로 취소한다. 지속 자식 프로세스·엔진을 일괄 종료하지 않는다.
- IPC 85개 명령의 인수·결과를 고정하고 DTO를 `src/ipc/`로 이동했다. `src/api.ts`는 호환 진입점, `src/queries.ts`는 현재 데이터·진행 중 요청·이벤트 반영을 담당한다. 별도 결과 캐시는 추가하지 않았다.
- Rust의 Transport를 분리하면서 소유권 lease와 재검사를 유지했다. 네트워크 생성은 기존 resources 모듈로 이동하고 Docker 집계·생성 결과 구조체를 도입했다. 모든 Rust JSON 응답을 재설계한 것은 아니다.
- `npm run check`, `npm run check:windows`와 기존 workflow의 소스 검사 정의를 추가했다. Node 내장 검사를 사용하며 의존성·버전·lock을 변경하지 않았다.
- 옛 `verify-navigation-cache.mjs`와 중복된 `verify-navigation.mjs`를 삭제하고 필요한 탐색·새로고침 검사는 현재 global-refresh·frontend-refinements 검사에 모았다. 데이터·입력·탭 유지와 중복 IPC를 확인하며 DOM 객체 동일성·개인 설치 경로를 요구하지 않는다. 필수 메뉴·탭을 확인하되 새 항목 추가를 실패 조건으로 삼지 않는다. 네이티브·격리 브라우저의 경계 검증을 유지하며 CDP 연결을 공유한다.
- EXE·ZIP 동봉 문서 목록을 통일했다. 과거 결과·조사 전체를 동봉하는 대신 필요한 문서와 온라인 링크를 제공한다. 예제·라이선스·소스 제공 자료는 보존한다.
- 사이트는 공개판 영수증·고정 소스의 고지/체크섬을 검증한다. 개발판과 버전이 달라도 공개판을 생성하며, 지운 구버전 다운로드를 원본 폴더에 복원하지 않는다. 미게시·미완료 검사를 차단한다. 이후 추가된 정확한 앱 해시별 prerelease 승인 예외는 [Pages 계약](../PAGES.md)을 따른다.

## 검증

최초 감사나 과거 설치판 검사 결과를 이번 수정의 통과로 합산하지 않았다. [검사 영수증](architecture-refactor.json)은 이번 소스 지문과 명령·화면 검사 결과를 묶는다.

초기 확인 중 잘못된 FFI 포인터 변환과 더 엄격한 이벤트 스냅샷 키 타입 오류를 발견해 수정한 뒤 재검사했다. 브라우저 자동화는 샌드박스 안의 별도 Chrome 연결이 끊겨, 같은 격리 프로필 절차를 허용된 로컬 실행으로 다시 확인했다. 최종 10개 검사는 종료 0이며 사용자 브라우저 프로필은 사용하지 않았다.

시험용 Chrome 프로필 4개(83,106,020바이트)는 관련 프로세스 종료·작업 폴더 내 경로·reparse point 부재를 확인한 뒤 삭제했다. 로컬 HTTP 미리보기도 종료했다. 저장소 밖 결정 HTML은 중요한 선택 16개·확인 사항 4개를 기록하고, 1,280×640 화면에서 한 화면 배치와 모바일 가로 넘침 없음을 확인했다.

## 남은 범위

후속 패키징 요청으로 새 앱·CLI·포터블 ZIP 제작과 내부 검증은 수행했다. 설치 EXE와 외부 빌드 승인 상태는 [별도 제작 기록](refactor-packages-20261116.md)을 따른다. 아래 항목은 이 구조 개편 검사 시점의 범위다.

원격 CI·새 앱/CLI 실행 파일 및 설치 EXE·ZIP 제작·실제 설치/제거·엔진 변경 E2E는 실행하지 않았다. 수정한 네이티브 탐색/전체 새로고침 검사는 현재 UI 조건과 문법만 확인했으며 실제 엔진 연결 검사는 남아 있다. 사이트의 공개 다운로드 fallback은 이번 실제 빌드에서 사용하지 않았고 Git/로컬 원본 경로를 검사했다. 0.1.10 설치판의 기존 Microsoft 탐지 원인은 미확정이며 새 소스 검사가 이를 해결하거나 안전성을 보증하지 않는다. 사용자 엔진·컨테이너·이미지·볼륨과 설치된 앱은 변경하지 않았다.
