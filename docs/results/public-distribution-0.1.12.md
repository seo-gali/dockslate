# 0.1.12 공개 배포

[GitHub Release](https://github.com/seo-gali/dockslate/releases/tag/v0.1.12)에 설치 EXE·포터블 ZIP·타사 고지 ZIP·SHA256SUMS를 공개했다. 공개 파일 4개, 총 101,364,006 bytes를 실제 다운로드해 저장한 SHA-256·GitHub digest와 대조했다.

**미서명 개발판이다. 내부 앱의 DeepInstinct MALICIOUS 탐지 1건은 오탐 여부 미확인이다. 사용자가 결과를 확인한 뒤 이 정확한 앱 해시의 prerelease 공개를 승인했다.** 설치 EXE·ZIP·CLI의 기록상 탐지는 0건이며 시간 초과·실패·미지원을 따로 기록했다. 큰 ZIP의 내부 전체 검사는 보장되지 않는다.

[공개 파일 영수증](public-distribution-0.1.12.json) · [제작·검사](release-0.1.12.md) · [백신 기록](virustotal-0.1.12.json)

전체 Desktop 이전, 오류가 난 원격 PC의 전체 설치·제거·콜드 부팅·롤백과 정식 서명은 미완료다. 기존 Release·사용자 데이터는 보존한다. 홈페이지 전환 결과는 공개 파일 영수증의 Pages 항목에 별도로 기록한다.
