# 0.1.13 공개 배포

[GitHub Release](https://github.com/seo-gali/dockslate/releases/tag/v0.1.13)에 설치 EXE·포터블 ZIP·고지 ZIP·SHA256SUMS를 공개했다. 공개 파일 4개를 실제로 다시 받아 크기·SHA-256·GitHub digest를 대조했다. 이전 0.1.12 Release와 로컬 원본은 보존했다.

[홈페이지](https://seo-gali.github.io/dockslate/)도 0.1.13으로 전환했다. 실제 다운로드 링크·체크섬과 CSS·스크립트·가이드의 배포 파일을 확인했고, 기존 고지 주소 20개는 모두 HTTP 200이다.

새 EXE·ZIP·앱·CLI의 VirusTotal 탐지는 모두 0건이다. 설치 EXE의 시간 초과 2·미지원 4, ZIP의 시간 초과 8·미지원 8은 정상 검사로 합산하지 않는다. 대용량 ZIP의 내부 전체 검사를 뜻하지 않아 앱·CLI도 따로 검사했다.

[공개 파일 영수증](public-distribution-0.1.13.json) · [제작·검사](release-0.1.13.md) · [백신 기록](virustotal-0.1.13.json)

미서명 개발판이다. 실제 Docker Desktop 두 엔진의 전체 이전, 운영 서비스, 전체 설치·제거·콜드 부팅·롤백은 미검증이다. 홈페이지 배포 커밋과 실행 번호는 공개 파일 영수증의 Pages 항목에 기록했다.
