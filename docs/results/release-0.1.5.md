# 0.1.5 설치판 준비

2026-10-31. 정리 결과·캐시 판정·파일 빌드 패널과 아래 여백을 수정했다. [기능 검증](cleanup-feedback.md)은 버전 메타데이터 변경 전 EXE의 실제 Windows 검사 12개와 알림 렌더링 검사 2개다. 기능 소스는 `3c40c49`에 커밋했으며, 이후 앱 루트 버전만 0.1.5로 올린다. 의존성 그래프와 엔진 구성은 변경하지 않는다.

0.1.5 앱·CLI 빌드와 locked/offline Rust 검사는 종료 0이다. 새 앱의 PE·엔진 응답 버전은 0.1.5이며 읽기 전용 Windows 검사 4개와 CLI 버전 명령 4개를 통과했다. 포터블·고지 ZIP과 설치 파일 내부 검증을 진행한다. 현재 공개 설치판은 0.1.4이다. 사용자가 0.1.5의 버전 변경·GitHub 설치 빌드 1회·검증 후 게시·구버전 앱 파일 삭제·임시 workflow 삭제를 승인했다. 승인 전 추가 원격 설치 빌드는 실행하지 않았다.

고지 문서 표지·현행 고지 ZIP 링크를 0.1.5로 맞춘 뒤 패키징한다. 이전 0.1.4 설치판·포터블의 고지 스냅샷이 가리키는 0.1.3 고지 링크는 보존한다.

**커널 보안 패치를 포함한 릴리스가 아니다.** [CVE-2026-98432 조사](cve-2026-98432-wsl.md)의 미패치 위험과 확인 범위를 유지하며 시스템·WSL·Ubuntu·Docker 업데이트를 실행하지 않는다. 실제 설치·제거, 전체 회귀, 공격 재현은 별도 미검증이다.
