# DockSlate 0.1.8

자동 시작 설정과 컨테이너 일괄 작업을 포함한 후속 빌드다. 엔진 자동 시작과 Windows 로그인 시 창 열기를 각각 선택할 수 있으며 기본값은 꺼짐이다. 컨테이너 표의 개별·전체 선택으로 시작·중지·재시작하고, 상태가 맞지 않는 대상은 건너뛰며 실패 사유를 표시한다.

중지된 기존 엔진을 첫 설치 화면으로 보내지 않는다. 재시작 후 비정상 종료 문구와 설정 여백을 수정하고, 일괄 작업 중 창 종료를 막는다. GitHub Actions의 전체 SHA 고정 검사도 포함한다. 의존성 버전과 사용자 데이터 형식은 유지한다.

설치 EXE·포터블 ZIP·고지 ZIP과 SHA256SUMS를 생성했다. [승인된 GitHub 빌드 1회](https://github.com/seo-gali/dockslate/actions/runs/42040328613)의 산출물을 GitHub digest와 대조한 뒤, 내부 앱·CLI·공식 구성 요소·문서·고지·보조 코드를 검사했다. ZIP 611개 파일 전수 대조와 CLI 버전 명령 4개도 통과했다. 파일별 크기·SHA와 검사 범위는 [배포 기록](release-0.1.8.json)에 남겼다. 패키지 문서는 제작 시점의 스냅샷이다. 현재 공개 사이트는 0.1.7을 유지한다.

[자동 시작·일괄 작업 검사 범위](startup-bulk-feedback.md): 화면·입력 거부는 확인했지만 실제 일괄 실행, 자동 시작 등록·엔진 자동 시작, Windows 로그인·재부팅, 설치 완료·제거는 아직 미검증이다. 과거 0.1.7 검사를 새 실행 파일의 전체 회귀 통과로 합산하지 않는다.
