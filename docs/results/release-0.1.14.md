# 0.1.14 제작·검사

Docker Desktop 조회 제한을 명령당 30초에서 120초로 늘리고, 검사 완료 뒤부터 승인 유효 시간 120초를 계산하는 수정본이다. 원본 조회에서 불필요한 DockSlate 프록시·Compose/Buildx 준비를 생략하고 실패한 엔진·명령 단계를 표시한다. 원본 중지·복사 제한과 승인·소유권 검사는 유지한다. 최신 사용·개발·웹 안내도 동봉한다.

현재 설치 EXE·ZIP을 제작 중이다. 공개 홈페이지는 검증된 0.1.13을 유지하며, 제작·로컬 실행 확인을 공개 배포로 표시하지 않는다. 정확한 새 파일의 백신 결과·정식 서명·실제 Docker Desktop 전체 이전은 별도다.

0.1.14 소스의 `npm run check`는 Node 17개·IPC 계약 89개/네이티브 등록 92개·TypeScript·문서·workflow·패턴 시크릿 검사에서 종료 0이었다. `scripts/check-windows.ps1 -Offline`는 격리 AppData에서 Rust 보안 30개·PATH 11개·실제 프로세스 7개가 통과했다. 기존 사용자·시스템 PATH와 엔진은 변경하지 않았다.

30초 제한과 승인 시간 계산의 수정 전 실패·수정 후 검사 및 원격 PC 미확인은 [조회 수정 기록](migration-timeout.json)에 남긴다. 의존성은 그대로이며 앱 자체 버전만 변경했다. 이전 0.1.13 배포 파일과 해시는 보존한다.
