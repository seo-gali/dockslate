다음 파일은 이름과 내용이 겹쳐도 실제 용도가 있어 유지했다.

- `target/windows-docker-cache`: `scripts/prepare-windows-docker.ps1`의 오프라인 빌드 입력.
- `target/windows-docker`: 공식 구성 요소·라이선스 검사와 패키징 입력.
- `target/release/libexec`: 직접 실행하는 개발용 Docker CLI가 읽는 실제 실행 파일.
- 현재 공개 0.1.9 원본과 배포 보류 중인 0.1.10 원본. 탐지된 0.1.10 EXE는 실행하지 않고 정확한 파일을 검토 자료로 보관.
- `licenses`, `docs/downloads`의 법적 고지·소스 원본과 내용이 다른 조사 원본·검사 기록.

삭제 후 원본 배포 파일 6개 해시·필수 경로 존재를 확인했다. `node scripts/check-workflow-pins.mjs`는 2개 workflow·6개 SHA 참조·25개 자체 검사·오류 0, `node scripts/verify-license-inventory.mjs`는 구성 요소 555개·고지 362개·소스 11개·누락 0으로 종료 0이다. 엔진·컨테이너·볼륨·설치된 앱·자동 시작 설정은 변경하지 않았다. 소스 코드 변경과 앱 재빌드는 이번 정리에 포함하지 않았다.
