# DockSlate 0.1.10

X로 창을 Windows 트레이에 숨기고 왼쪽 클릭으로 복원한다. 오른쪽 메뉴는 열기·컨테이너·이미지·전체 새로고침·설정·완전 종료이며 한영 설정을 따른다. 완전 종료는 진행 중 작업의 기존 종료 방지를 유지하고 앱 연결만 정리한다. 엔진·컨테이너는 중지하지 않으며 설치 준비창의 완료·취소 종료는 유지한다.

앱·CLI 빌드와 실제 0.1.10 Windows 트레이 검사 15개, 포터블 ZIP 622개 파일과 오프라인 CLI 버전 명령 4개를 확인했다. [GitHub 빌드 1회](https://github.com/seo-gali/dockslate/actions/runs/42331749779)의 EXE를 공식 digest와 대조하고 내부 앱·CLI·공식 구성 요소·고지·문서·PATH 도우미를 확인했다. 임시 workflow·입력 ZIP은 삭제했다.

**0.1.10 공개 배포는 보류했다.** 2026-11-07 03:13:59 UTC의 정확한 EXE 해시 검사에서 Microsoft가 `Trojan:Win32/Wacatac.B!ml`로 탐지했다. VirusTotal EXE 1/50(시간 초과 20·미지원 5), ZIP 0/67(미지원 7·검사 실패 1)이다. [원본 검사 결과](virustotal-0.1.10.json)에 조회 시각·파일별 해시·결과 링크를 기록했다. 오탐 여부는 확인되지 않았으며 Microsoft 검토 요청은 제출하지 않았다. 설치 EXE는 실행하지 않았고, 경고를 우회하거나 재패키징하지 않았다. 기존 0.1.9 사이트·Release·태그를 유지한다.

의존성 버전·데이터 형식 변경은 없다. 실제 마우스 좌표·Explorer 클릭, 작업 중 종료 방지·전체 설치/제거·로그인·재부팅은 미검증이다. 파일별 SHA·실제 검사·공개 상태는 [제작 기록](release-0.1.10.json)에 구분한다. 패키지 문서는 제작 시점의 스냅샷이며 이후 기록 수정 때문에 다시 만들지 않았다.
