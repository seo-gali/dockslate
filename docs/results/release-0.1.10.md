# DockSlate 0.1.10

X로 창을 Windows 트레이에 숨기고 왼쪽 클릭으로 복원한다. 오른쪽 메뉴는 열기·컨테이너·이미지·전체 새로고침·설정·완전 종료이며 한영 설정을 따른다. 완전 종료는 진행 중 작업의 기존 종료 방지를 유지하고 앱 연결만 정리한다. 엔진·컨테이너는 중지하지 않으며 설치 준비창의 완료·취소 종료는 유지한다.

승인된 빌드·공개 배포를 진행 중이다. 기존 0.1.9 공개판을 보존한다. 의존성 버전·데이터 형식 변경은 없다. 파일별 SHA·실제 검사·공개 상태는 [제작 기록](release-0.1.10.json)과 [트레이 검사](tray-background.md)에 구분한다. 패키지 문서는 제작 시점의 스냅샷이다.
