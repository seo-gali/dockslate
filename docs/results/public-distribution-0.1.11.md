# 0.1.11 공개 배포

[GitHub Release](https://github.com/seo-gali/dockslate/releases/tag/v0.1.11)에 EXE·포터블 ZIP·타사 고지 ZIP·SHA256SUMS를 공개했다. 공개 파일 4개, 총 101,360,873 bytes를 실제로 받아 저장한 SHA-256·GitHub digest와 대조했다. 미서명 개발판이며 기존 Release는 유지한다.

[기계 판독 영수증](public-distribution-0.1.11.json) · [제작·검사](release-0.1.11.md) · [백신 결과](virustotal-0.1.11.json)

설치 EXE·ZIP·앱·CLI의 탐지는 0건이다. ZIP에는 시간 초과 2·실패 1·미지원 7개가 있으며 내부 모든 파일이 분석된 것으로 해석하지 않는다. 전체 Docker Desktop 이전, 전체 설치·제거·콜드 부팅·롤백과 정식 서명은 미완료다.
