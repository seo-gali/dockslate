# 검색·API·성능 점검

대상은 DockSlate의 React 화면과 로컬 Tauri IPC다. 회원·테넌트 API는 구현되어 있지 않다. 검색은 Hub 1곳, 로컬 목록·로그·JSON 필터 8곳을 확인한다.

## 변경 기준

| 범위 | 실패 조건 | 변경 후 확인 |
| --- | --- | --- |
| Hub 검색 | 빈 입력이 IPC로 전달되거나 이전 검색 결과가 남음 | 빈 값·공백·누락 거절, 입력 변경 시 결과 초기화, 0건 유지 |
| 로컬 검색 | 공백 처리 불일치·검색 중 추가 조회 | 검색어를 한 번 정규화하고 이미 읽은 데이터만 필터링 |
| 목록 렌더링 | 이미지·정리·기록 전체를 DOM에 생성 | 50행 페이지, 검색·탭 변경 시 초기화 |
| 상세 로딩 | Containers 진입 때 터미널·파일·JSON까지 로드 | 해당 탭의 첫 사용까지 코드 로딩 지연 |
| 초기 번들 | 앱의 빌드 상태 훅과 함께 설정·결과 화면까지 로드 | 상태는 유지하고 패널 코드는 Builds에서 로드 |
| 요청·캐시 | 동일 빌드 상세·빌더 검사를 동시에 중복 요청 | 진행 중 요청 공유, 실패 뒤 다시 조회 가능. 기록 8MiB·24건, 빌더 2MiB·24건 LRU |

## API 10개 항목의 적용 범위

| 항목 | 소스 확인 결과 |
| --- | --- |
| 버전 | Docker API 버전 협상 구현. 프런트엔드·IPC는 함께 배포 |
| 멱등성 | 변경 잠금·일회성 승인 토큰 존재. 익명 생성의 응답 유실 후 중복 재시도는 남음 |
| 오류 | IPC 오류는 문자열. 안정된 공통 코드·결과 불명 계약은 미구현 |
| 내부 구조 | 목록 DTO 사용. Inspect 원문은 요청한 상세 JSON 기능 |
| 호출 수 | 통합 snapshot 공유, 통계 일괄 요청. 행별 기본 목록 조회 없음 |
| 페이지·필터 | Hub 128자·25개, 통계 요청 256개 제한. 로컬 목록 DOM 제한 보완 |
| 권한 | 제한된 로컬 명령·배포판 소유권·엔진 ID 검사. 다중 테넌트 서버가 아님 |
| 시간·역압 | 개별 명령 시간·출력 상한 존재. 전체 읽기 동시성·통계 배치 마감 시간은 미구현 |
| 일관성 | 변경 뒤 snapshot 재조회·실행 직전 재검사. 작업 성공 후 확인 실패 표현은 보완 필요 |
| 관측성 | 일부 작업 ID 존재. 공통 요청 ID·경로별 메트릭은 미구현 |

## 검증

| 파일 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 진입 JS | 278,558바이트 | 268,944바이트 |
| Containers 목록 JS | 55,676바이트 | 26,379바이트 |
| Containers CSS | 5,103바이트 | 1,013바이트 |

파일 크기 감소는 로딩 분리 결과다. 진입 파일은 3.45%, Containers 목록 JS는 52.62% 감소했다. 전체 기능 JS 합계·실제 렌더 횟수·응답 시간이 그 비율로 줄었다는 뜻은 아니다. 파일 탐색기 CSS 4,091바이트도 해당 탭으로 분리했다. UI는 기존 SVG·시스템 폰트를 사용하며 배포 파일에 래스터 이미지·웹 폰트는 없다.

- `npm run build`: TypeScript·Vite 빌드 통과.
- `node scripts/inspect-bundle.mjs docs/results/api-performance-bundle.json`: [배포 크기 측정](api-performance-bundle.json) 통과.
- `node scripts/verify-frontend-refinements.mjs .analysis/performance-production-session.json docs/results/api-performance-browser.json`: [분리 Chrome 검사 10개](api-performance-browser.json) 통과. 실제 배포 화면·7개 메뉴·언어 저장·탭 유지·상세 코드 미리 로드하지 않음 확인. 백엔드를 주입하지 않았다.
- `node scripts/verify-search-boundary.mjs .analysis/search-performance-session.json docs/results/search-boundary-browser.json`: [검색 경계 19개](search-boundary-browser.json) 통과. 잘못된 입력 13개는 IPC 전에 거절하고 정상 형식 6개는 입력 검증을 통과해 백엔드 미연결 검사까지 도달했다. 변경 전에는 잘못된 검색어도 데스크톱 연결 검사로 넘어갔다. Rust는 원래 빈 검색어를 거절했으므로 전체 데이터 유출을 재현한 것으로 기록하지 않는다.

검색 9곳을 정규화했다. 로컬 빈 필터는 이미 읽은 목록을 다시 표시하며 서버 전체 조회를 호출하지 않는다. Hub 입력 변경은 이전 결과·오류를 지우고 이전 요청 응답도 무시한다. 실제 Hub 결과 0건은 빈 상태를 유지한다.

스냅샷은 컨테이너·이미지·사용량·네트워크를 공유하므로 목록 행별 N+1 조회는 확인되지 않았다. 통계는 최대 4개 병렬 개별 Docker 요청이며 개별 5초 제한이 있다. 목록 전체의 통계 배치 마감 시간은 아직 없다. SQL·DB 쿼리를 사용하는 앱은 아니다.

최신 EXE·연결된 엔진의 51개 이상 실제 목록, 캐시 동시성·이전 응답, 상세 탭 상태 보존, Hub 응답 0건은 이번 실행에서 검증하지 않았다. `scripts/verify-registry-search.mjs`에는 빈 값·공백·보이지 않는 문자·입력 초기화 검사를 추가했지만 최신 EXE에서는 실행하지 않았다. 새 EXE 실행·사용자 데이터 변경·의존성 추가·파일 삭제는 없다. 패널 코드는 원래 훅 파일에서 옮겼고 중복 구현은 남기지 않았다.
