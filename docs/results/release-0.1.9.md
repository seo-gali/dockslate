# DockSlate 0.1.9

설치·제거 후반부의 환경 변경 알림을 전체 약 2초의 대기 예산으로 처리한다. 등록 처리 시작·결과·경과 시간과 알림 단계를 구분해 표시한다. 응답이 느린 프로그램은 알림 대기를 생략하며 필요하면 해당 프로그램을 다시 열어야 한다.

이 변경은 0.1.9에 새로 생성하는 설치·제거 프로그램에 적용된다. 첫 업그레이드에서 실행되는 이전 버전의 제거 프로그램까지 변경하는 것은 아니다.

[실제 NSIS 검사](installer-delay.md)에서 지연 응답 창 24개가 있을 때 설치·제거 알림 함수는 각각 2,015ms에 반환했다. PATH·등록 보존 검사 9개도 통과했다. 이 결과는 전체 삭제·PowerShell 시작 시간이나 당시 사용자가 겪은 지연 원인을 확정하는 검사가 아니다.

설치 EXE·포터블 ZIP·고지 ZIP과 SHA256SUMS를 생성했다. [GitHub 빌드 1회](https://github.com/seo-gali/dockslate/actions/runs/42232618099)의 산출물을 GitHub digest와 대조한 뒤 내부 앱·CLI·공식 구성 요소·문서·고지·보조 코드를 검사했다. 포터블 ZIP 615개 파일 전수 대조와 CLI 버전 명령 4개도 통과했다. 의존성 버전·사용자 데이터 형식은 바꾸지 않았다. 파일별 크기·SHA와 검사 범위는 [배포 기록](release-0.1.9.json)에 남겼다. 패키지 문서는 제작 시점의 스냅샷이다.

후속 [공개 배포](public-distribution-0.1.9.md)에서 GitHub Release와 홈페이지를 0.1.9로 전환하고 공개 파일의 SHA-256을 대조했다. 정확한 0.1.9 EXE·ZIP의 VirusTotal 공개 검사를 완료했다. 실제 설치·제거·네이티브 GUI·컨테이너 작업·엔진 재시작은 이 제작·게시 과정에서 수행하지 않았다. 기존 버전 파일의 사용자 삭제 상태를 복원하거나 함께 커밋하지 않았다.
