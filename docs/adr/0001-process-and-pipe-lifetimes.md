# ADR 0001: 프로세스·파이프 수명

상태: 채택 · 기록일: 2026-11-24 · 기존 구현의 결정을 주석에서 이전함.

## 배경

CLI의 부모가 끝나도 자식이 핸들을 붙잡을 수 있다. 제한 시간·입출력·소유권은 같은 실행 수명으로 다룬다.

## 영향

프로세스 종료와 스트림 종료를 별도로 확인한다. 읽기 제한 시간이 설치·이전 같은 변경 작업을 강제 종료하는 정책으로 바뀌면 안 된다.
