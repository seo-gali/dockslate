DockSlate

사용 방법

Windows 11 x64 · WSL 2.4.10+ · WebView2 · 최초 설치 시 인터넷

  1. 설치하고 엔진 준비

    설치 EXE를 실행합니다. 엔진 준비 대상과 영향을 확인하고 Docker Engine 설치 및 시작을 승인합니다.

  2. 이미지 받기 → 실행

    이미지 → Docker Hub에서 검색·선택해 받은 뒤 로컬 이미지에서 실행을 누릅니다. 이름과 내 PC 포트를 설정하고 컨테이너를 생성합니다.

  3. 컨테이너 확인

    목록에서 상태와 포트를 확인합니다. 이름을 누르면 로그·터미널·파일이 열립니다.

도움말

터미널에서 Docker 명령 쓰기

설치 후 새 CMD·PowerShell을 여세요. 포터블은 ZIP 전체를 풀고 bin\docker.exe를 사용합니다.

docker ps
docker compose version
Dockerfile · Compose로 빌드하기

빌드 → 파일에서 빌드를 열어 파일을 선택합니다. 지원 구성을 확인하고 빌드한 뒤 실행합니다. Compose 가져오기는 제한된 구성을 지원합니다.

MongoDB에 연결이 안 될 때

컨테이너 실행 상태와 내 PC 포트를 확인하세요. 32768 → 27017이면 Compass 주소는 mongodb://127.0.0.1:32768/입니다. 실제 포트는 컨테이너마다 다릅니다.

앱을 지우면 데이터도 사라지나요?

앱 제거로 전용 WSL 배포판·이미지·볼륨을 자동 삭제하지 않습니다. 엔진 중지도 데이터를 지우지 않습니다.
