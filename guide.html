빠른 시작

Windows 설치 EXE 포터블 ZIP 폴더의 EXE 다운로드 페이지

0.1.0 · 미서명 개발 버전. ZIP은 전체를 풀고 bin·libexec 폴더를 함께 유지하세요.

보안 확인 미완료. 이전 브라우징 데이터 접근 경고의 원인은 미확인입니다.

필수: Windows 11 x64 · WSL 2.4.10+ · WebView2 · 최초 설치 시 인터넷

3단계로 시작하기

  1. 설치하고 엔진 준비

    설치 EXE를 실행합니다. 엔진 준비 화면에서 대상과 영향을 확인하고 Docker Engine 설치 및 시작을 승인합니다.

  2. 이미지 받기 → 실행

    이미지 메뉴에서 이미지를 받은 뒤 실행을 누릅니다. 이름과 내 PC 포트를 정하고 컨테이너를 생성합니다.

  3. 컨테이너에서 확인

    상태와 포트를 확인합니다. 이름을 누르면 로그·터미널·파일을 볼 수 있습니다.

필요할 때 확인하세요

터미널에서 Docker 명령 쓰기

설치 후 새 CMD·PowerShell을 여세요. 포터블은 압축을 푼 폴더의 bin\docker.exe를 사용합니다.

docker ps
docker compose version
Dockerfile · Compose로 빌드하기

빌드 → 파일 가져오기에서 Dockerfile 또는 Compose 파일을 선택합니다. 구성을 확인하고 빌드한 뒤 실행합니다. Compose 가져오기는 제한된 구성을 지원합니다.

MongoDB에 연결이 안 될 때

컨테이너가 실행 중인지 확인하고 표의 내 PC 포트를 사용하세요. 32768 → 27017이면 Compass 주소는 mongodb://127.0.0.1:32768/입니다. 실제 포트는 컨테이너마다 다릅니다.

앱을 지우면 데이터도 사라지나요?

앱 제거로 전용 WSL 배포판·이미지·볼륨을 자동 삭제하지 않습니다. 엔진 중지도 데이터를 지우지 않습니다.
